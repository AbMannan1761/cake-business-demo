# Project Overview: Cake Business Website

## 1. Introduction
This project is a modern, responsive, and beautifully designed web application for a boutique cake business. Built with React and Vite, the website is optimized for performance and aesthetics, ensuring an excellent user experience across all devices.

## 2. Live Demo
You can interact with the live version of the website here:
👉 **[Live Website Demo](https://AbMannan1761.github.io/cake-business-demo/)**

## 3. Key Features
- **Premium UI/UX Design**: Elegant typography (Playfair Display) and warm, artisanal color palettes designed to reflect the quality of the cakes.
- **Single Page Application (SPA)**: Fast and seamless page transitions without reloading, powered by React Router.
- **Mobile Responsive**: Fully optimized for mobile devices, which is critical for Instagram traffic.
- **Dynamic Menu**: A structured layout to showcase signature cakes, prices, and descriptions.
- **Contact Form**: Integrated UI for customer inquiries and custom cake orders.

## 5. Technology Stack
- **Frontend Framework**: React 19
- **Build Tool**: Vite (for lightning-fast builds and HMR)
- **Styling**: Vanilla CSS with CSS Variables for a maintainable design system.
- **Routing**: React Router DOM (HashRouter for static hosting compatibility)
- **Deployment**: GitHub Actions & GitHub Pages
